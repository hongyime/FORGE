Self-Healing Rules

The supervisor should make the machine safer by refusing work, not by trying harder. Default mode is observe/dry-run. Apply mode needs explicit local config.
  • Single-instance lock for autopilot and resume batches; stale lock break only after PID/dead-owner check.
  • RAM guard: skip live child work if available memory is below a configured threshold.
  • CPU/load guard: skip or reduce parallelism when load is already high.
  • Backoff after failures, with maximum attempts per boot/day.
  • Limits: small default feed/import/resume/monitoring caps; no unbounded loops.
  • Docker health integration: start only after required containers are healthy; degrade to report-only when unhealthy.
  • Packaged-tool guard: live connector phases run only when the required local binary and templates are present and version/hash checks pass.
  • Never run live target import/start without feed, ROE ID, scope manifests, and explicit apply config.
