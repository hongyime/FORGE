FORGE Autonomous Target Loop Plan

Updated 2026-08-29. Scope merges the original target-feed/autopilot plan, the later free-first connector/dashboard requests, the packaged Go tool requirement, and the robustness review. Secret material is intentionally omitted.

Operating Rule

Implement only free, local, deterministic, or read-only features by default. Anything requiring paid APIs, account keys, live targets, ticket writes, SOAR webhooks, scheduled-task registration, or Docker mutation remains opt-in behind explicit config and apply flags. When local config enables auto-live and the configured ROE env var is present, apply cycles can promote directly into the guarded live path after the normal preflight gates pass.

User Flow

1. ConfigureSet local ROE env, autostart config, optional Supabase/CTI refs, and low-memory limits.
2. Drop InputsPlace CTI, Burp/JUnit, ProjectDiscovery, Censys/runZero, or asset delta files under imports/.
3. Build FeedDry-run by default; apply writes merged canonical targets with source provenance.
4. Queue ImportsReady local inputs import with explicit limits; deferred or blocked items stay visible.
5. Gate LiveROE, scope, resources, Docker health, cooldown, and lock checks must pass.
6. ExecuteNew targets start, failed runs resume, due monitoring runs, reports and dashboard refresh.
7. Learn OutwardNewly observed scoped assets feed back into target lists for the next cycle.

Done Target Feed Loop

  • forge automation feed-build creates imports/target-feed.json.
  • Sources: local DB seeds, reports/dashboard artifacts, CTI files, connector payloads, optional read-only Supabase tables.
  • Autopilot runs feed-build before import unless --skip-feed-build.

Done Free Artifact Imports

  • Burp/JUnit DAST XML imports as scoped active-validation evidence.
  • Censys/runZero-style JSON/CSV asset deltas import fingerprints and topology.
  • No scanner execution or provider calls are required.

Done Metrics And Matrix

  • Exposure metrics: first_seen, last_seen, open_days, recurrence, MTTR.
  • Active-validation matrix: ATT&CK/control family, proof type, freshness, retest state.
  • Closed-loop remediation dashboard: owner, SLA, ticket state, sync state, proof freshness.

Free-First Implementation Status

Done Command Consolidation

  • Make automation, doctor, targets resume, connectors plan/run, and report review the daily-use layer.
  • Add static daily-use command grouping to command review.
  • Flag commands that are public but absent from README.md or DAILY_USE.md.

Done ProjectDiscovery Cloud Export Import

  • Local deterministic mode uses existing ProjectDiscovery binaries plus offline ProjectDiscovery Cloud JSON exports.
  • Cloud API sync stays plan-only until the operator supplies a key through env/secret store.
  • Preserve scan assets, scoped nuclei-style findings, template counts, and provenance in connector payloads.
  • Discovery artifact imports now support bounded --dry-run and --limit execution with no-write JSON counts.

Done Autostart Follow-Up

  • Bounded redacted apply-mode autostart log rotation lives under the Forge data dir.
  • Docker readiness inspects container state/health when Docker responds.
  • Keep OS/Docker startup pointed at guarded-autostart, not raw forge-autopilot.

Plan Only Paid Or Keyed Providers

  • Supabase live read-only API, ProjectDiscovery Cloud, Censys API, runZero API, ticket APIs, and SOAR/SIEM webhooks require operator-owned keys.
  • Default implementation path remains offline import, dry-run, and explicit --apply.

Done OpenRouter Free Model Selection

  • Do not hardcode a specific free model name.
  • At runtime, query OpenRouter model metadata and enable the backend only when a zero-price/free model is proven.
  • Prefer capable free families such as Qwen, DeepSeek, Llama, Gemma, or Mistral; skip OpenRouter if no free fit is advertised.

Done Packaged Go Tools

  • Self-heal checks the supplied binaries: nuclei, gopls, gitleaks, amass, ffuf, gobuster, mapcidr, tlsx, uncover, naabu, dnsx, httpx, katana, subfinder.
  • Resolution now prefers local tool dirs and ~/go/bin before PATH shims.

Safety Gates

  • No raw secrets in repo, docs, plans, state, or logs. The pasted OpenRouter key must be rotated by the operator outside the repo.
  • Dry-run remains default for feed-build/import/resume/monitoring/autostart planning.
  • Live target actions require ROE, scoped manifests, normal Forge live gates, and explicit apply/start flags.
  • Startup automation fails closed on low memory, low disk, Docker failure, active locks, cooldown/backoff, or missing local config.
  • Docker and Windows startup wrappers apply their own bounded failure backoff so repeated wrapper-level failures surface instead of silently retrying forever.
