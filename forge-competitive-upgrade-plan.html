Key Findings

1. FORGE's credential extraction matches CrackMapExec
FORGE uses impacket secretsdump API (no subprocess), quieter than running secretsdump.exe but less comprehensive than LSASS memory access (sekurlsa::logonpasswords).
Source: forge/utils/post/collectors/win_creds.py:1-205, Vectra AI Mimikatz deep dive (2024)
2. Missing cloud credential forensics for AWS STS tokens
STS-token-decoder parses AWS session tokens, extracts account ID, creation timestamp, region, encrypted user data, and recovers region public keys for offline verification. FORGE extracts AWS keys but doesn't decode session token structure.
Source: forge/automation_secret_auto_feed.py:1-407, STS-token-decoder GitHub README
3. Attack path analysis lacks hybrid AD/Azure coverage
BloodHound v5.13.0 shows synced user paths between AD and Entra ID. FORGE has cloud asset graph scoring but no AD-specific cypher queries or hybrid path primitives.
Source: SpecterOps blog "Hybrid Attack Paths" 2024-08-02, BloodHound v5.13.0 release notes
4. Persistence capabilities exceed CrackMapExec and Covenant
FORGE supports 11 persistence methods across 12 reverse shell techniques with stealth modes (IPv4 decimal encoding, hidden files). CrackMapExec focuses on enumeration, Covenant uses implants with fewer persistence doors.
Source: forge/hardening/linper_offensive.py:1-200
5. No lateral movement primitives
CrackMapExec provides psexec, wmiexec, smbexec. Covenant offers remote shell through Grunt implants. FORGE can install persistence but cannot move between hosts programmatically.
Source: MITRE ATT&CK S0488, SpecterOps Covenant blog 2025-02-17
6. Unique sudo hijack attack not in competitors
Linper module intercepts sudo password entries via alias injection and exfiltrates to attacker-controlled RHOST via curl with decimal-encoded IP for stealth. Not present in Mimikatz, CrackMapExec, BloodHound, or Covenant.
Source: forge/hardening/linper_offensive.py:400-438 (sudo hijack impl)
