# FORGE Purpose

FORGE is an automated, deterministic, traceable security assessment platform.
It performs authorized assessments against specific scope set by a human.

The platform automates routine assessment work while keeping scope, phase,
concurrency, and audit controls in force. Its records must preserve provenance,
supporting evidence, and decisions so results can be reviewed and reproduced.
